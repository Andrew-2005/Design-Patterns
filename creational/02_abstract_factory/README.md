# Абстрактна фабрика (Abstract Factory)

**Категорія** — твірні патерни.

Абстрактна фабрика створює сімейство пов'язаних продуктів через спільний контракт. Клієнт вибирає одну фабрику і отримує сумісні між собою компоненти.

**Проблема.** Звіт містить заголовок і список. Вибір формату має застосовуватися до обох компонентів, щоб під час формування звіту не змішати HTML і Markdown.

**Реалізація.** `Heading` і `BulletList` описують продукти. `ReportFactory` оголошує два методи створення. `HtmlReportFactory` повертає `HtmlHeading` і `HtmlBulletList`, а `MarkdownReportFactory` повертає `MarkdownHeading` і `MarkdownBulletList`. Клієнт `render_report` використовує обидва компоненти однієї фабрики.

**Застосування та компроміси.** Патерн допомагає перемикати цілі сімейства компонентів. Для нового формату достатньо додати нове сімейство та фабрику. Додавання спільного виду компонента, наприклад таблиці, потребує оновити контракт і всі фабрики.

Запуск із кореня репозиторію

```powershell
python creational/02_abstract_factory/example.py
```
