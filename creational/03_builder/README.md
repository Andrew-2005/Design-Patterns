# Будівельник (Builder)

**Категорія** — твірні патерни.

Будівельник ділить створення складного об'єкта на кроки. Готовий продукт з'являється після складання та перевірки накопичених параметрів.

**Проблема.** Організатор додає зупинки поступово, а транспорт може вибрати окремо. План вважається готовим, коли маршрут містить щонайменше одну зупинку.

**Реалізація.** `Excursion` є готовим продуктом, `ExcursionBuilder` описує кроки, а `RouteBuilder` накопичує зупинки й перевіряє їх наявність. Функція `plan_city_excursion` виконує роль директора й задає готовий порядок кроків.

**Застосування та компроміси.** Патерн доречний для об'єктів із кількома необов'язковими параметрами або повторюваними послідовностями складання. Перевірка зосереджена в `build`. Для простого об'єкта окремий будівельник додає зайвий код.

Запуск із кореня репозиторію

```powershell
python creational/03_builder/example.py
```
