# Прототип (Prototype)

**Категорія** — твірні патерни.

Прототип створює новий об'єкт копіюванням уже налаштованого зразка. Клієнт викликає метод клонування, а тип об'єкта визначає, які дані копіювати.

**Проблема.** Викладачеві потрібно підготувати варіант роботи зі спільним набором запитань та окремим порядком відповідей. Якщо копія ділить вкладені списки із шаблоном, редагування варіанта змінить обидва.

**Реалізація.** `QuizPrototype` описує метод `clone`. `Quiz` реалізує його через `deepcopy` і створює незалежні списки відповідей. Демонстрація змінює порядок відповідей у варіанті, зберігаючи початковий порядок у шаблоні.

**Застосування та компроміси.** Патерн підходить, коли наявний шаблон простіше скопіювати, ніж налаштовувати кожен екземпляр заново. Глибоке копіювання потребує часу й пам'яті пропорційно обсягу вкладених даних.

Запуск із кореня репозиторію

```powershell
python creational/04_prototype/example.py
```
