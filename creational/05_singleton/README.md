# Одинак (Singleton)

**Категорія** — твірні патерни.

Одинак забезпечує один екземпляр класу і надає повторний доступ до нього. У цьому прикладі обидва компоненти кіоска записують події в один журнал.

**Проблема.** Модулі оплати та друку створюють посилання на журнал у різних місцях, а події мають з'явитися в одному списку в порядку виконання.

**Реалізація.** `KioskEventLog` зберігає єдиний екземпляр на рівні класу. Метод `__new__` створює його під час першого виклику та повертає повторно. Функції клієнта приймають контракт `EventSink`, а демонстрація перевіряє тотожність через `is`.

**Застосування та компроміси.** Один екземпляр забезпечує спільний стан у межах процесу. Накопичення такого стану між викликами ускладнює ізоляцію перевірок. Цей приклад розрахований на однопотоковий запуск.

Запуск із кореня репозиторію

```powershell
python creational/05_singleton/example.py
```
