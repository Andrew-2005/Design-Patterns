# Фабричний метод (Factory Method)

**Категорія** — твірні патерни.

Фабричний метод передає вибір конкретного продукту підкласу. Спільний процес використовує продукт через один контракт і викликає фабричний метод, коли продукт треба створити.

**Проблема.** Оформлення відправлення однакове для наземного й морського маршрутів, але кожен маршрут потребує свого транспорту.

**Реалізація.** `Transport` описує продукт, а `Truck` і `Ship` реалізують його. `Logistics` задає спільне оформлення й оголошує фабричний метод `create_transport`. `RoadLogistics` і `SeaLogistics` визначають, що саме він створює.

**Застосування та компроміси.** Сценарій доречний, коли спосіб створення залежить від типу відправника. Новий вид транспорту можна додати окремим підкласом. Кожна нова комбінація створювача й продукту може збільшити кількість класів.

Запуск із кореня репозиторію

```powershell
python creational/01_factory_method/example.py
```
